# Product

## Register

product

## Users

Developers and technical users who need to inspect, edit, execute, and revisit HTTP API requests without opening a large API-development workspace. They invoke the utility while working in another application and expect it to be immediately ready for paste or keyboard input.

## Product Purpose

API Panel provides a fast, local-first API-testing surface that lives in the macOS menu bar. Success means a user can press Command-Shift-C, paste a URL or curl command, edit the request, execute it, inspect a full-width response, and recover any previous request from automatic history with minimal interruption.

## Brand Personality

Native, focused, trustworthy. The interface should feel like a restrained Apple system utility: familiar enough to use immediately, precise enough for technical work, and quiet when not needed.

## Anti-references

- Postman-scale chrome, persistent sidebars, collection trees, and workspace complexity.
- Bruno's manual-save behavior and any workflow where executed requests disappear from history.
- Empty response panes, decorative placeholders, dashboards, and permanent split views before content exists.
- Web-dashboard styling, custom theme palettes, neon developer-tool aesthetics, and decorative glass cards.
- A fake notch silhouette or window geometry that competes with the real menu bar.

## Design Principles

1. Appear ready, then get out of the way.
2. Preserve every meaningful action automatically.
3. Reveal interface only when the corresponding data exists.
4. Use familiar system behavior before inventing custom behavior.
5. Keep secrets local, explicit, and absent from history or logs.

## Accessibility & Inclusion

Support keyboard-only operation, VoiceOver labels and focus order, semantic status text, sufficient hit targets, and system accessibility preferences. Follow Light Mode, Dark Mode, Increased Contrast, Reduce Transparency, Reduce Motion, and the user's accent colour. Never rely on colour alone to communicate method, response, or failure state.
