# Curlman v0.2.7

This maintenance release restores full mouse interaction in the native macOS compact panel.

## Fixed

- The native compact panel can become the key window after its title bar is removed.
- Restore, close, method, URL, paste, and send controls now receive clicks in minimized mode.
- Added a regression test for compact-panel keyboard and mouse eligibility.

## Install

Download `Curlman.dmg`, open it, and drag Curlman into Applications. The native build supports Apple Silicon and macOS 14 or newer.

Electron users can continue to run the cross-platform edition from source:

```sh
npm install
npm run dev
```
