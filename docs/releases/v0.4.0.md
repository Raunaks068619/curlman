# Curlman v0.4.0

## Added

- Fold and expand multiline JSON objects and arrays from the editor gutter.
- Show compact key or item counts for collapsed JSON structures.
- Search request payloads and responses with native macOS find controls or Command-F.
- Build the open-source Electron edition as Windows x64 and Linux x64 installers from native GitHub runners.
- Copy or save Electron responses and rename or rerun local History entries.

## Improved

- Give the line-number gutter a clearer background and separator from JSON content.
- Reset folds when the payload or response changes so every new document opens fully expanded.
- Keep folding available only for valid, formatted JSON while preserving search for raw text and headers.

## Install

```sh
brew tap Raunaks068619/curlman
brew trust Raunaks068619/curlman
brew install --cask curlman
```

Or download `Curlman.dmg`, open it, and drag Curlman into Applications. The native app is signed, Apple-notarized, and universal for Apple Silicon and Intel Macs.

Windows and Linux users can download the unsigned community Electron packages from the same GitHub release or run the source with `npm install` and `npm run dev`.
