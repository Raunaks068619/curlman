# Curlman v0.2.6

This maintenance release makes the Electron tray icon a complete app control instead of a window-only toggle.

## Fixed

- Clicking the Electron menu-bar icon on macOS now opens a native menu.
- The tray menu includes Open Curlman, New Request, History, Settings, and Quit Curlman.
- Windows and Linux retain a standard tray context menu while a primary click opens Curlman.
- Tray destinations open the window and switch directly to the requested workspace.

## Install

### Native macOS

Download `Curlman.dmg`, open it, and drag Curlman into Applications. The build supports Apple Silicon and macOS 14 or newer. It is ad-hoc signed but not Apple-notarized, so Control-click and choose Open on the first launch.

### Electron on macOS, Windows, or Linux

```sh
git clone https://github.com/Raunaks068619/curlman.git
cd curlman
npm install
npm run dev
```

Node.js 22.12 or newer is required. Prebuilt Electron installers are not included in this release.
