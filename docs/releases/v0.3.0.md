# Curlman v0.3.0

Curlman is now ready for a broader native macOS preview with a faster first-run experience and more complete request editing.

## Added

- A two-page native onboarding flow with shortcut setup, a safe test request, and a GitHub project card.
- Editable form URL-encoded and multipart request bodies.
- Request timeout, redirect, and cookie-session controls.
- Draft recovery with authentication secrets stored separately in Keychain.
- A universal native build for Apple Silicon and Intel Macs.
- Developer ID signing, notarization, release verification, and cross-platform release automation.

## Improved

- Onboarding uses a centered 600-point layout with stronger typography and spacing.
- Imported cURL requests preserve more request behavior and warn about unsupported options.
- The release workflow verifies signatures, architectures, checksums, stapling, and Gatekeeper acceptance.

## Install

Download `Curlman.dmg`, open it, and drag Curlman into Applications. Curlman requires macOS 14 or newer.

Homebrew installation:

```sh
brew install --cask Raunaks068619/curlman/curlman
```

Electron users can run the cross-platform edition from source:

```sh
npm install
npm run dev
```
