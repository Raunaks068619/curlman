# Curlman v0.4.1 — native JSON folding fix

This is a native macOS maintenance release. Windows and Linux users can continue using the unchanged [v0.4.0 Electron installers](https://github.com/Raunaks068619/curlman/releases/tag/v0.4.0).

## Fixed

- Restore visible line numbers and JSON folding arrows in large responses, including after the editor grows or scrolls.
- Fix a TextKit layout exception when collapsing large JSON documents.
- Preserve the complete original JSON when folding and expanding.
- Add a native editor regression test covering large responses and fold/expand behavior.

## Install or update

Download **Curlman.dmg** below and drag Curlman into Applications, replacing the previous app. Your local history and settings are preserved.

The native app and DMG are Developer ID signed, Apple-notarized, and stapled. The app supports Apple Silicon and Intel Macs running macOS 14 or newer.

Existing Homebrew users:

```sh
brew update
brew upgrade --cask raunaks068619/curlman/curlman
```

First install:

```sh
brew tap Raunaks068619/curlman
brew trust Raunaks068619/curlman
brew install --cask raunaks068619/curlman/curlman
```

Launch Curlman after installation; it runs in the menu bar. The default shortcut is Command-Shift-C.
