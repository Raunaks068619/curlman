# Curlman v0.2.5

Curlman is now available in two equal editions: a native Swift menu-bar app for macOS and a consistent Electron app that runs from source on macOS, Windows, and Linux.

## Highlights

- Paste multiline cURL commands directly into the focused command field.
- Edit methods, URLs, params, headers, JSON or raw bodies, and authentication.
- Send requests from the keyboard and inspect formatted full-width responses.
- Keep automatic local history with search, restore, rerun, pin, and delete actions.
- Copy the currently edited request back to runnable cURL.
- Minimize into a compact command strip and choose a custom global shortcut.
- Import `--get` with `--data-urlencode` as editable query params.
- Use a visible native menu-bar/tray icon in light or dark mode.

## Install

### Native macOS

Download `Curlman.dmg`, open it, and drag Curlman into Applications. The build supports Apple Silicon and macOS 14 or newer. It is ad-hoc signed but not Apple-notarized, so Control-click and choose Open on the first launch.

### Electron on macOS, Windows, or Linux

```sh
git clone https://github.com/Raunaks068619/curlman.git
cd curlman
npm install
npm run dev
```

Node.js 22.12 or newer is required. Prebuilt Electron installers are not included in this release.
